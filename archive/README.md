# Archive

Elements that have been replaced on the site, kept here so they can be restored.
This folder is not published (it is listed in `.vercelignore`).

## hero-slide-1/ (replaced 8 November 2026)

The first hero slide originally used the generated tower artwork instead of a photograph.

- `slide-markup.html`: the original slide HTML from `index.html`
- `art-tower.svg`: the original artwork (a copy; the live file in `assets/img/` is still used by an Insights card)

To restore it, paste `slide-markup.html` over the first `<article class="slide ...">` in `index.html`.
